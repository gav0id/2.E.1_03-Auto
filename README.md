Ejercicio 2.E.1 03 - Auto

Lógica del programa
Implementé un constructor que inicializa la marca y el modelo. Además, le agregué comportamiento a la clase mediante tres métodos específicos: `encender()` y `apagar()` (que modifican el valor de la variable booleana e imprimen una acción) y `mostrarEstado()` (que utiliza una estructura condicional `if/else` para evaluar e informar si el auto se encuentra prendido o apagado).

Dentro del método `main`, desarrollé la siguiente lógica:
1. Instancié un único objeto `Auto` pasándole al constructor los valores "Corsa" y "Chevrolet".
2. Ejecuté una secuencia de llamadas a los métodos de ese objeto para alterar y verificar su estado de forma dinámica.
3. Comprobé por consola el estado inicial (que por defecto en Java es `false`, es decir, apagado), luego llamé al método para encenderlo, verifiqué el cambio de estado, lo volví a apagar y realicé una comprobación final.
